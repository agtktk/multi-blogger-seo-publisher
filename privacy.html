접근하는 Google 데이터와 이용 목적

  • 계정 연결 — Google 계정 이메일과 이메일 인증 여부로 선택한 계정과 실제 승인 계정이 일치하는지 확인합니다. OAuth 액세스 토큰과 갱신 토큰으로 승인된 요청을 보냅니다.
  • Blogger — 관리 권한이 있는 블로그의 이름, ID, 주소와 게시글 ID, 제목, 본문, 라벨, 공개 상태 및 URL을 조회합니다. 사용자가 지시한 게시글 작성, 수정, 초안 저장, 발행, 삭제 및 발행 결과 확인에 사용합니다.
  • Google Cloud — 선택한 프로젝트에서 Blogger API 할당량과 사용량을 조회해 발행 관리에 사용합니다.
  • Google Sheets — 시트 연동을 사용하면 사용자가 지정한 문서와 범위에서 원고나 키워드를 읽고, 내보내기를 요청하면 발행 이력을 지정한 시트에 기록합니다.

저장과 보호

계정과 블로그 연결 정보, 원고, 발행 작업과 이력, 진단 로그는 사용자 PC의 앱 데이터 폴더에 보관합니다. Windows DPAPI로 로컬 OAuth 토큰을 보호합니다. Blogger 웹 편집기 연동을 사용하는 경우 계정별 로컬 Chrome 프로필에 로그인 세션이 유지될 수 있습니다.

서비스 간 전송과 공유

Google 계정 확인과 승인된 Blogger, Cloud, Sheets 작업을 위해 필요한 데이터는 해당 Google 서비스로 전송됩니다. 공개 발행을 선택한 원고와 이미지는 해당 블로그의 공개 설정에 따라 방문자에게 표시됩니다. 앱은 운영자 서버에 Google 계정 데이터나 인증 토큰을 수집하지 않으며, 이를 판매하거나 광고 목적으로 사용하지 않습니다.

선택한 기능에 따라 AI 원고 생성 시 키워드와 작성 지침이 Codex CLI를 통해 OpenAI에 전달됩니다. ImgBB나 R2 업로드를 사용할 때는 선택하거나 생성한 이미지 파일이 해당 서비스에 전송됩니다.

보관 기간과 삭제

로컬 기록은 사용자가 앱이나 데이터 폴더에서 삭제할 때까지 남을 수 있습니다. Blogger 계정 연결을 해제하면 해당 연결의 로컬 토큰 및 Chrome 프로필을 제거하는 절차가 실행됩니다. 원고와 발행 이력은 로컬 데이터 폴더에서 삭제할 수 있습니다. 사용자는 Google 계정에서 앱의 접근 권한을 철회할 수 있습니다. Blogger 게시글과 Sheets에 이미 기록한 내용은 각 서비스에서 관리합니다. Google 계정의 앱 연결 관리
