1. 수집하는 정보

Multi Blogger SEO Publisher는 사용자가 직접 연결한 Google 계정 이메일, Blogger 블로그 정보, Google OAuth 인증 토큰을 프로그램의 로컬 PC에 저장할 수 있습니다.

2. 이용 목적

저장된 정보는 Google Blogger 블로그 조회, 게시글 작성·수정·예약 발행, Google Cloud API 사용량 조회를 위해서만 사용됩니다.

데이터는 기본적으로 사용자의 Windows PC에 저장됩니다. OAuth 토큰은 Windows 보안 저장소(DPAPI)를 이용해 보호하며, 운영자가 별도의 서버로 전송하거나 판매하지 않습니다.

4. 제3자 서비스

이 프로그램은 사용자의 승인에 따라 Google Blogger API와 Google Cloud API를 사용합니다. 해당 서비스의 이용에는 Google의 개인정보처리방침과 약관이 적용됩니다.

5. 삭제 및 철회

프로그램에서 계정 연결을 해제하거나 로컬 데이터 폴더를 삭제할 수 있습니다. Google 계정의 타사 앱 액세스 권한 페이지에서 언제든지 OAuth 권한을 철회할 수 있습니다.
